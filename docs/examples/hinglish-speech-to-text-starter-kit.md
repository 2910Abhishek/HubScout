## TL;DR

We recommend the mistralai/Voxtral-Mini-4B-Realtime-2602 model (Apache-2.0 license) for Hindi-English mixed speech-to-text, as it explicitly supports both languages, fits within the 16 GB GPU VRAM budget (~10.6 GB at bf16), and permits commercial use. Pair it with the Voxtral Realtime streaming method described in the associated paper, which provides natively streaming ASR with sub‑second latency. For evaluation or lightweight adaptation, use the DynamicSuperb/CodeSwitchingSpeechIdentification_ASCEND dataset (CC‑BY‑SA 4.0), a small code‑switching speech corpus.
